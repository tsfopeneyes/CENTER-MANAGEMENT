# 기존 로그인 유지 및 캘린더 작업 분리 — 2026-08-31

사용자 요청에 따라 새 로그인 전환을 보류하고, 캘린더 작업본에서 해당 서버 의존성을 제거했다.
운영 DB 변경이나 배포는 수행하지 않았다.

## 보관

프로젝트 내부 `backups/deferred-auth-2026-08-31T08-13-13-297Z`에 변경 전 파일,
tracked-changes.patch, 신규 인증 화면/서버/전환 SQL/도구를 보관했다.
보관 폴더는 Git 및 Firebase 배포 대상에서 제외된다. 비밀값이 있는 .env 파일은 복사하지 않았다.
이 보관본은 배포 준비 완료 상태가 아니다. 임시 회원 분류 및 가입 실패 복구 문제를 먼저 고쳐야 한다.

## 분리 내용

- App 라우트, 로그인/가입, 사용자·관리자 프로필 비밀번호 변경과 관리자 초기화를 기존 방식으로 복원.
- 학생 대시보드 공용 파일은 비밀번호 변경 계약만 복원하고 모집·캘린더 변경은 유지.
- dispatch-notification은 기존 인증 확인/계정 연결 경로로 복원. account-auth 함수와 배포 설정은 활성 경로에서 분리.
- Firebase 사전 검사는 빌드 및 기존 로그인 경로 존재/새 인증 의존성 부재를 검사하도록 변경.
- 회원 병합 중지, 사용하지 않는 비밀번호 추측 코드 제거, 게스트 공통 비밀번호 대신 null 저장은 유지.
  이 변경들은 새 인증 서버가 필요하지 않으며, 사용자 기록을 이동하거나 삭제하지 않는다.
