# 학생 프로그램 카드·월 전체 일정 개선

2026-08-31 사용자 요청에 따른 로컬 변경. 운영 배포나 운영 DB 적용은 하지 않았다.

## 변경

- 홈과 센터 탭이 함께 사용하는 `ProgramCard`를 통일했다. 모집 예정 상태에도 기존 카드 구조를 사용한다.
- 뱃지는 `모집 예정`, 하단은 한국 시간 기준 `9/7(월) 오후 5시 모집 예정` 형식이다.
  모집 시작 전 하단 버튼은 비활성이며 상세 본문/신청 가능 여부 검사는 유지한다.
- 이미지가 없으면 정사각형 이미지 자리와 기본 달력 그림을 렌더링하지 않는다.
  이미지 있는 카드와 같은 줄이어도 불필요하게 카드 높이를 늘리지 않는다.
- 사용자가 공개를 승인한 이미지·짧은 소개·장소·정원은 예정 카드에서도 표시한다.
  기존 운영 공개 뷰에는 이 필드가 없어, 별도 후속 SQL을 로컬에 준비했다.
  `supabase/migrations/20260831010300_publish_program_card_metadata.sql`은 뷰의 허용 필드만 추가한다.
  원본 데이터, 본문 접근 정책, 비공개 글 제외, 인증/회원/로그는 변경하지 않는다.
- `NoticeModal` 하단 마감 안내 위의 별도 모집 뱃지 행을 제거했다.
- 후속 요청으로 모집 예정 카드는 클릭해도 안내창을 열지 않는다. 홈/센터 공용 카드의 클릭·호버 효과와
  캘린더 예정 카드의 상세 이동을 중지한다. 모집이 시작되면 기존 상태 판정에 따라 다시 동작한다.
  관심 등록·모집 시작 푸시는 가능 여부만 검토했으며 관심 데이터 저장, 예약 발송 또는 실제 푸시는 추가/실행하지 않았다.
- 학생 캘린더 최초 진입과 월 이동 시 날짜 미선택 상태로 시작해 그 달 전체 일정을 날짜순으로 표시한다.
  날짜를 누르면 해당 날짜로 필터링되며 `월 전체 보기`로 복귀할 수 있다. `오늘`은 오늘 날짜를 선택한다.
  후속 요청에 따라 월 전체 목록은 한국 시간의 오늘·이후 날짜를 먼저 오름차순으로,
  그 뒤 월초부터 어제까지를 오름차순으로 표시한다. 회색 배경은 후속 요청으로 취소하고 모든 카드를 원래 흰색으로 유지한다.
  오늘 일정은 시간이 지났더라도 오늘 그룹에 유지한다. 판정 기준은 모집 종료가 아니라 일정 날짜다.
  앞뒤 달의 달력 여백 날짜는 월 전체 목록에 포함하지 않는다. 여러 날에 걸친 일정은 해당 날짜마다 표시한다.
  당직/운영 시간/휴관 안내는 날짜를 선택했을 때만 표시한다.

## 검증

- `scripts/test-student-card-calendar.mjs`: 예정 문구·한국 시간, 신청 차단, 월/날짜 필터,
  월 경계·여러 날짜 일정·빈 날짜 검사.
  오늘 우선·미래/과거 그룹별 오름차순, 지난 달/다음 달, 한국 시간 자정 경계와 같은 날 순서 유지도 검사한다.
- `scripts/test-program-privacy.mjs`: 최초 보호 SQL 뒤 후속 공개 SQL을 독립 DB에서 실행.
  카드 필드 공개, 본문/JSON 비공개, 비공개 글 제외, 원본 보존과 쓰기 권한을 검사.
- 캘린더 규칙·색상·당직 회귀 테스트.
- 최종 `npm run build` 통과. 기존 대형 번들·브라우저 호환 목록 경고는 남아 있다.
- `scratch/student-card-calendar-preview.html`: 외부 요청/실계정을 사용하지 않는 로컬 검증 화면.
  이미지 유무·모집 상태, 월 전체→날짜 선택→월 전체 복귀→다음 달 이동을 확인했다.
  모바일에서도 가로 넘침이 없고, 이미지 없는 예정/모집 중 카드에는 이미지 요소가 0개다.
  후속 정렬 검증에서는 8/31 → 8/7 → 8/21 순서를 확인했다. 이후 배경색 변경만 취소했다.
  예정 카드 본문을 실제 클릭해도 상세 열기 콜백이 실행되지 않고, 모집 중 카드 클릭은 정상 유지됨을 확인했다.
  캘린더의 예정 프로그램 카드도 비활성 상태임을 확인했다.
