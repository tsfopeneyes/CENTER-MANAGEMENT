# 캘린더 개편: 구현 및 운영 반영 메모

## 동작

- 프로그램 작성의 진행 일정은 넓은 화면에서 날짜·오전/오후 시간·소요 시간을 한 줄로 표시한다.
  모집 시작/종료도 같은 회색 입력창과 시간 선택기를 사용하며 소요 시간은 두지 않는다.
  좁은 화면은 입력창이 잘리지 않게 줄을 나눈다. 모집 시각의 1분 단위 값을 보존하고,
  날짜를 고르기 전 시간만 조정해도 임의 날짜나 모집 시작을 생성하지 않는다.
- 장소와 모집 정원은 넓은 화면에서 나란히 표시한다. 모집 기간은 추가 테두리 박스 없이
  같은 카드의 아래 행에 두며 다른 항목과 같은 제목 스타일을 사용한다. `한국 시간` 문구만
  제거하고 기존 한국 시간 입력·저장 규칙은 유지한다.
- 학생 캘린더: 월 이동, 오늘, 날짜 선택, 지난 프로그램 상세, 센터/비공개 필터 유지.
- 디자인: 기존 파란 요일 원형 표시, 부드러운 흰색 카드와 날짜 선택 표시 유지.
  프로그램 목록은 왼쪽 날짜, 오른쪽 제목·시간·장소와 화살표 형태를 사용한다.
- 월간 날짜 칸은 배경 하이라이트 없이 검은색 일정 이름과 유형별 색상 바만 표시하며
  날짜 칸과 선택일 목록 모두 프로그램을 대관보다 먼저 정렬한다.
- 선택일 목록에서 프로그램/대관/센터 일정 배지를 구분한다. 모집 상태 배지는 프로그램 배지와 함께 표시한다.
- 캘린더 안내 문구: `센터 일정`, `함께할 수 있는 일정을 확인해보세요`.
- 색상 설정: 관리자 `카테고리 관리`에서 센터·스처 프로그램도 수정할 수 있다. 20색 팔레트와 미리보기 제공.
  기존 `calendar_categories`의 고유 이름과 `color_theme`를 사용하며 DB 구조를 변경하지 않는다.
  프로그램 색상은 처음 저장할 때만 기본 항목으로 추가한다. 기본 이름/삭제는 잠그고 기존 일정 데이터는 수정하지 않는다.
  관리자 필터·달력·모바일 상세와 학생 달력·유형 배지가 같은 설정을 사용한다.
  학생 대관 카드의 이름·날짜는 검은색을 유지하며 유형 색상은 배지 배경과 달력 강조선에 반영한다.
  학생 화면 복귀/1분 간격으로 설정을 갱신한다. 저장 실패·중복 이름·다른 관리자의 색상 변경 시 명시적으로 알린다.
- 휴무: 정기 운영 설정·센터별 휴관 일정·하이픈 추석연휴를 빨간 날짜에 반영한다.
  휴관 일정은 일정 개수와 목록에서 제외한다. 선택한 하이픈 휴관일에는 당직 카드 대신
  `하이픈 휴관일입니다` 안내를 표시한다. 공휴일은 등록된 휴관 일정/당직표 기준이다.
- 신청 프로그램: 한국 시간의 모집 시작·종료 일시. 시작 포함, 종료 제외.
- 모집 예정: 제목, 배지, 신청 시작 안내만 표시. 카드·학생 상세·공유 페이지에서 같은 판정 사용.
- 프로그램 탭의 `진행·모집 예정` 목록에도 안전한 일정 전용 조회를 통해 모집 예정 카드를 표시한다.
  모집 시작 전 본문·이미지·장소·신청 항목은 노출하지 않는다.
- 모집 중: 상세와 신청 공개. 필수 정보가 미완성이면 배지는 모집 중, 상세/신청은 준비 중.
- 모집 종료: 종료 배지, 상세 열람 가능. 프로그램 완료·출석·후기·포인트 처리는 별개.
- 기존 프로그램: 시작 일시가 NULL이면 기존 공개 방식 유지. 종료 처리는 새 신청 경로에서 재검사.
- 오픈 프로그램: 모집 기간을 적용하지 않음. 챌린지는 진행 중 모집 가능하되 종료일 이내로 제한.
- 하이픈 당직: 날짜별 한 명, 프로필에 설정한 이미지와 이름. 이미지 미설정/조회 실패 시 기본 아이콘.
  당직자가 미등록이거나 당직 없음인 날짜는 당직 카드를 숨긴다. 휴관일 안내는 유지한다.
  이높플레이스에는 새 당직 영역 없음.
- 하이픈 당직 입력은 이름 검색 후 스태프 계정을 선택한다. 이름만 입력한 값은 저장하지 않으며 계정 ID와 이름을 함께 저장한다.
  동명이인은 프로필과 계정 끝 네 자리로 구분한다. 기존 이름만 있는 배정은 표시하되 수정할 때 계정을 선택해야 한다.
- 하이픈 날짜별 당직 입력은 일정 관리에만 둔다. 사용자 요청으로 근무 현황의 새 `오늘의 당직` 입력 영역은 제거했다.
  근무 현황의 기존 재실 카드와 이높플레이스 당직 선택은 유지한다. 학생 홈 오늘 당직은
  `center_duty_assignments`의 날짜별 기록을 사용한다. 기존 날짜 없는 `DAILY_DUTY_STAFF`의 하이픈 값은 더 이상 표시/저장 기준으로 쓰지 않는다.
  미배정 날짜에는 이전 당직자를 이월하지 않으며, 당직 없음도 동일하게 반영한다. 이높플레이스와 현재 재실 상태는 기존 방식 유지.
  과거 날짜에 현재 재실 상태를 적용하지 않는다. 한국 시간 자정에 근무 현황의 날짜가 바뀐다.
- 일정 관리의 당직 스태프 입력칸을 열면 선택된 이름과 관계없이 전체 후보를 표시한다. 기존 8명 제한을 제거하고
  전체/검색 결과 수와 스크롤 목록을 제공한다. 이름을 입력할 때만 검색하며 키보드 선택 시 해당 행으로 스크롤한다.
- 당직 저장은 원래 읽은 상태·스태프 ID·이름·표시 문구를 비교하며, 다른 수정이 먼저 저장되었으면 덮어쓰지 않는다.
  같은 이름의 다른 계정으로 변경된 경우와 미배정 날짜의 동시 등록도 충돌로 처리한다. 입력 중 자동 갱신은 초안을 유지하고 안내한다.
  같은 화면의 저장 알림, 실시간 변경, 화면 복귀로 당직표를 갱신하고 실시간 지원이 없는 환경은 30초 조회로 보완한다.
  이 연결 변경은 로컬 코드만 수정했으며 기존 DB 구조·당직 기록·근무 로그·날짜 없는 설정 값은 변경하지 않았다.

다른 네트워크/권한 오류는 자료가 없는 것으로 처리하지 않고 오류를 표시한다.
모집 컬럼이 없으면 프로그램 저장은 명시적인 안내와 함께 중단하며, 입력 내용은 유지한다.

## 배포 전 확인할 한계

- 새 당직 쓰기·모집 전 본문 편집은 실제 인증 ID가 서버 전용 관리자 목록에 있어야 한다.
  로컬 프로필만 남은 세션은 관리자 재로그인이 필요하다. 공개 목록만 내려온 경우 편집을 차단한다.
- 기존 `users`의 공개 조회/수정 정책은 별도 위험이다. 로그인 검증 값 조회와 기존 로그인 방식의
  조합은 인증 우회 위험이 있으므로 이번 본문 RLS만으로 전체 인증 보안이 완결된 것은 아니다.
  회원 정보 조회 축소, 로그인/계정 복구의 서버 검증, 필요시 인증 수단 재설정은 별도 전환 및 배포가 필요하다.
  사용자의 배포 금지 요청을 유지하기 위해 이번 변경에서 로그인 구조를 임의로 교체하지 않았다.
- 새 화면을 배포하기 전 기존 화면은 새 모집 예정 프로그램을 목록에서 보지 못할 수 있다.
  원본 조회가 막히는 정상 결과다. 새 로컬 화면은 안전한 일정 전용 목록과 기존 공개 글을 합쳐 표시한다.
- 기존 글의 모집 시작 날짜를 추측하거나 일괄 초기화하지 않는다.
- 정기 운영 시간에는 날짜별 과거 이력이 없으므로 과거 화면에 현재 등록 기준임을 명시한다.
- 이미지 인식은 이 대화에서 수행한다. 앱 내 이미지 자동 인식 서버는 추가하지 않았다.
- 자동 모집 시작 푸시 알림은 추가하지 않았다. 관리자가 선택하는 기존 알림 기능만 유지한다.

## 검증

- 시간 입력은 날짜 칸과 같은 높이·테두리·우측 아이콘을 쓰는 `TimePicker`로 통일했다.
  프로그램/모집/일반 일정에서는 `오후 2:37` 형태로 표시하고, 작은 선택창에서 오전/오후와 시·분을 고른다.
  선택 완료(또는 목록에서 Enter) 전에는 기존 값을 변경하지 않으며 취소·Esc·바깥 클릭은 편집을 취소한다.
  `node scripts/test-time-picker.mjs`는 하루 1,440개 분 값의 왕복 변환, 자정/정오, 빈 값과 잘못된 값을 검증한다.
- 날짜 입력은 공통 `DatePicker`의 작은 달력으로 통일했다. 프로그램 일시·모집 시작/종료,
  오픈/챌린지 프로그램 기간, 일반 일정 시작/종료·반복 종료일에 적용한다.
  날짜는 `yyyy-MM-dd`로 유지하고 기존 시간 값·필수 입력 검사를 보존한다.
  팝업은 폼 바깥에 렌더링해 잘림을 방지하고, 화면 가장자리에 맞춰 위치를 조정한다.
  방향키/Enter/Space 선택, Esc로 달력만 닫기, 월/연도 전환, 선택 날짜 지우기를 지원한다.
  `scratch/calendar-integration.html`의 FORM/EVENT 모드로 실제 컴포넌트를 가상 응답에서 검증한다.
- `scratch/duty-picker-preview.html`: 실제 당직 입력·근무 현황 컴포넌트를 가상 스태프 24명으로 실행한다.
  근무 현황의 하이픈 당직 입력 제거, 전체 24명/검색 결과 수, 마지막 항목 선택, 선택 후 전체 목록 재열기,
  키보드로 8명 이후 항목까지 이동·스크롤·선택을 확인했다. 실제 조회·저장은 하지 않는다.

## 다음 달 이미지 처리

센터는 하이픈으로 고정하고 연월을 확인한다. 판독한 날짜·이름을 검토한 뒤 새 월의
시드 SQL을 추가한다. 빈칸은 삭제나 기존 배정 해제로 해석하지 않는다. 기존 날짜와
충돌하는 변경은 먼저 보여주며, 관리자 화면에서도 다른 관리자의 변경을 조용히 덮어쓰지 않는다.
