`npm run build` 통과(기존 번들 크기/브라우저 호환 목록 경고는 남음).
로컬 브라우저에서는 외부 저장이 차단된 가상 계정으로 이름·비밀번호 입력, 동명이인 선택,
학생 화면 이동을 확인했다. 계정 연결 안내 표시·확인 버튼·Escape 닫기도 확인했다.
이는 운영 로그인이나 운영 백업 복구 시험 결과가 아니다.

사용자는 외부 DB 연동이 없다고 확인했으며 DB 비밀번호 재설정 완료를 알렸다.
이어 CA 인증서를 내려받았다. 값은 채팅/코드로 전달받지 않았다.
사용자 직접 입력으로만 실행하는 로컬 암호화 백업 도구를 준비하고 가상 자료 테스트를 통과했다.
실제 백업/복구 성공은 아직 확인 전이며 운영 전환 차단 조건은 그대로 유지한다.
